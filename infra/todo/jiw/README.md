`infra/todo/day-XX.md`가 "계획(할 일)"이라면, 이 폴더는 "실제로 무엇을 했는지"에 대한 기록이다.

- 파일은 `day-XX.md`(계획 문서와 동일한 번호)로 나누고, 계획에 없던 사전 준비/의사결정은 `day-00-planning.md`에 남긴다.
- 매 작업 직후 바로 기록한다 (몰아서 나중에 쓰지 않는다).

## 기록 형식

```
## YYYY-MM-DD

### 무엇을 했는지 한 줄 요약
- 상세 내용 / 실행한 명령어 / 결과
- 산출물/파일 경로
- 다음에 필요한 것
```
