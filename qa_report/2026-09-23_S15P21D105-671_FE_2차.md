## 4. 발견 결함

### D-1. 홈 플로팅 상담 버튼이 카드 정보를 가림

- 심각도: Minor
- Jira: 미등록(Jira 버그 등록 필요)
- 환경: Android 16 에뮬레이터, 1080×2400, Expo Go
- 재현 절차:
  1. 시연 계정으로 홈에 진입한다.
  2. 총자산 카드가 화면 우하단 상담 캐릭터 위치에 오도록 스크롤한다.
  3. 총자산 구성 범례를 확인한다.
- 기대 결과: 상담 버튼과 총자산 범례가 겹치지 않는다.
- 실제 결과: 상담 캐릭터가 `입출금` 범례 일부를 덮는다.
- 참고: `frontend/src/pages/home/components/CoachChatFloatingButton.styles.ts`

### D-2. 발견 전체 보기 요약 문구의 마지막 한 글자가 고립됨

- 심각도: Trivial
- Jira: 미등록(Jira 버그 등록 필요)
- 환경: Android 16 에뮬레이터, 1080×2400, Expo Go
- 재현 절차:
  1. 발견 랜딩을 건너뛴다.
  2. 발견 홈에서 `전체 보기`를 누른다.
  3. 상단 요약 카드의 제목을 확인한다.
- 기대 결과: 제목이 한두 줄 안에서 자연스러운 어절로 줄바꿈된다.
- 실제 결과: 마지막 `요`가 별도 줄에 표시된다.
- 참고: `frontend/src/pages/discovery/DiscoveryInsightsScreen.tsx`, `DiscoveryInsightsScreen.styles.ts`

## 6. 비고

- `adb logcat`에서 `ReactNativeJS` 또는 `AndroidRuntime` 오류는 확인되지 않았다.
- 가계부는 재진입 시 선택 월과 스크롤 위치를 유지했다. 촬영 시 항상 상단부터 시작해야 한다면 탭 재선택으로 상단 이동 여부를 한 번 더 확인한다.
- 발견 랜딩 완료 여부는 앱 저장소에 남는다. 촬영 단말에서는 촬영 전에 발견 탭에 한 번 진입해 `건너뛰기`까지 완료한다.
- 계좌·카드 번호는 화면에서 마스킹됐지만, API 원문이 서버에서 마스킹되는지까지는 네트워크 응답을 직접 캡처하지 않아 별도 확인하지 않았다.
- `expo install --check` 외의 TypeScript·ESLint 검사는 통과했다.
